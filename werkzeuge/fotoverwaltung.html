Nicht verbunden – es wird der ZIP-Weg benutzt.
Der Schlüssel wird nur in diesem Browser gespeichert und ausschließlich an GitHub gesendet – an sonst niemanden.
Schlüssel erstellen – Anleitung in 7 Schritten
  1. Bei GitHub anmelden und diese Seite öffnen:
    github.com/settings/personal-access-tokens/new
  2. Token name: z. B. Fotoverwaltung
  3. Expiration: z. B. 1 Jahr (danach einfach neu erstellen)
  4. Repository access: „Only select repositories" → Ferienhaus-Mara-Website auswählen
  5. Permissions → Repository permissions → Contents: auf „Read and write" stellen. Sonst nichts ändern.
  6. Unten auf „Generate token" klicken
  7. Den angezeigten Schlüssel sofort kopieren (er wird nur einmal gezeigt) und oben einfügen → Verbinden

Der Schlüssel gilt nur für dieses eine Repository und nur für Dateien. Geht er verloren, bei GitHub löschen und einen neuen erstellen.

So läuft es: Alles passiert hier auf deinem Gerät – es wird nichts hochgeladen. Wenn du fertig bist, bekommst du eine ZIP-Datei. Die entpackst du und lädst den Inhalt bei GitHub hoch. Eine Anleitung liegt im Paket bei.
